# golang-vdp-demo 0.2 Sync Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bring the stdlib-only Go demo from VDP 0.1 to 0.2: transform evaluation (§3.8), strict member rejection (§3.10), per-node rendering (§8), transform failure rules (§9.4/§9.6), discovery `mappers` (§13.2), with the VDP test corpus vendored and passing.

**Architecture:** A new ordered-JSON value type (`vdp/jsonvalue.go`, parsed with `json.Decoder` tokens) carries document order so `$entries` is deterministic; `vdp/transform.go` parses transforms into a validated AST and evaluates them to plain Go values for `html/template`. Descriptor parsing becomes strict-member (`x-` exempt). The resolver carries transforms on `Node` and holds a mapper registry; rendering becomes per-node. The demo API emits per-slot transforms (leaf templates rewritten to their new fixed contracts) and the corpus from the VDP repo is vendored under `vdp/testdata/corpus/`.

**Tech Stack:** Go stdlib only (repo rule). Tests: `go test ./...`. TDD: vendored corpus fixtures are the failing tests written first.

## Global Constraints

- **Stdlib only** — no external modules.
- **Git:** repo `master`, human-only attribution, sentence-case subjects, no AI trailers, commit-don't-push until the user confirms (per workspace conventions).
- **Corpus is canonical:** fixtures are copied verbatim from `../VDP/tests/` (tag v0.2.0-alpha). Sync rule: re-copy when the VDP corpus changes; never hand-edit copies. Record this in `vdp/testdata/corpus/README.md`.
- **Spec semantics** (from §3.8.2, condensed): pointers RFC 6901, `""` = whole input; missing → null; `$map` non-array → null; `$entries` non-object → null, document order, `{"key","value"}` pairs, `$to` element-relative; `$get`/`$default` (explicit null indistinguishable from absent); `$count` array len / object member count / else null; `$merge` shallow, last wins, non-objects skipped; mapping keys must not start with `$`; unknown `$` member or bad pointer = invalid descriptor (§9.3); `$mapper` top-level only, unknown mapper = slot failure (§9.1), root transform failure = error template only, never raw fallback (§9.4 r2); `_view`/`_views` stripped from transform input (§4.2); independent projection — every node evaluates against the original representation.

### Task 1: Ordered JSON values (`vdp/jsonvalue.go`)

Types: `type JSONValue struct { Kind Kind; Keys []string; Members map[string]*JSONValue; Items []*JSONValue; Scalar any }` with `ParseJSON([]byte) (*JSONValue, error)` (json.Decoder token walk, `UseNumber` off — scalars as float64/string/bool/nil to match encoding/json), `(*JSONValue).Pointer(ptr string) *JSONValue` (RFC 6901: `~1`/`~0` decode, array index `^(0|[1-9][0-9]*)$`, nil on miss), `(*JSONValue).Plain() any` (plain maps/slices/scalars), `StripDescriptor(*JSONValue)` (delete `_view`/`_views` members + keys). Tests: parse/pointer/escaping/order preservation (`{"z":1,"a":2}` keys stay `[z a]`), Plain round-trip.

### Task 2: Transform AST (`vdp/transform.go`)

`type Transform struct` AST: kinds pointer | mapping (ordered keys) | list | projection | entries | defaulted | count | merge | mapper. `ParseTransform(json.RawMessage) (*Transform, error)` — validation errors for: unknown `$` member, mapping key starting with `$`, invalid pointer syntax anywhere, `$map` without `$to`, `$mapper` not at top level, wrong operand types. `(*Transform).Eval(input *JSONValue) any` implementing the semantics above (mapper kind never evaluates — resolver handles it). `(*Transform).MapperURI() string`. Unit tests per construct + validation rejections.

### Task 3: Vendor the corpus (`vdp/testdata/corpus/` + `vdp/corpus_test.go`)

Copy `../VDP/tests/{transforms,rendering,descriptors}` verbatim + README with the sync rule. `corpus_test.go`: (a) every `transforms/<case>` — parse input ordered, apply transform (absent file = identity → Plain of input), compare to expected via `reflect.DeepEqual` on plain values; (b) `rendering/` — root+slot models with `StripDescriptor`; (c) `descriptors/valid` parse+Validate OK, `descriptors/invalid` rejected. ### Task 6: Resolver + mappers (`vdp/resolve.go`)

`Node` gains `Transform *Transform`. `Resolver` gains `Mappers map[string]func(any) any` (registered by the client; key = URI matched verbatim) + `RegisterMapper`. During resolve: node with `$mapper` transform not in registry → slot failure path (§9.1: skip slot, log to Trace) — at the root, resolution error `ErrRootTransform`. Referenced descriptors: warn-level trace when a fetched reference carries a transform (SHOULD NOT, §3.7) but accept. Tests: unknown mapper slot skipped, root error, known mapper carried.

### Task 7: Per-node rendering (`render/render.go`)
